# Задачи до mid-review

Исполнителей выбирает команда. Эти задания также предназначены для GitHub Issues.

## Подготовить данные и зафиксировать split

Цель: общий воспроизводимый набор данных для всех моделей.

- [ ] Проверить доступ к Criteo Display Advertising и ресурсный бюджет.
- [ ] Зафиксировать источник, checksum, подвыборку и seed.
- [ ] Описать признаки, пропуски, cardinality и долю положительного класса.
- [ ] Сохранить единый train/validation/test split; обосновать способ разбиения.
- [ ] Учить словари и статистики только на train, определить unknown categories.
- [ ] Добавить инструкцию подготовки в data/README.md.
- [ ] Согласовать выходной формат с парой, реализующей модели.

Готово: другой участник получает те же строки и split по инструкции. Данные не коммитятся. Если Criteo недоступен, согласовать смену постановки до самостоятельного понедельника.

## Реализовать небольшую DNN и исходную DCN 2017

Цель: проверить вклад cross-ветки при одинаковой deep-ветке и схеме embeddings.

- [ ] Согласовать интерфейс входа с подготовкой данных.
- [ ] Реализовать DNN и исходный cross-слой x_next = x0 * sum(x_l * w_l) + b_l + x_l.
- [ ] Проверить размерности и broadcasting на небольшом примере.
- [ ] Получить конечный loss и убедиться, что модель переобучается на маленьком батче.
- [ ] Добавить параметры запуска, seed, early stopping по validation.
- [ ] Подготовить сравнение DNN и DCN с 1, 2, 3 cross-слоями.
- [ ] Посчитать параметры с embeddings и без них.

Готово: другой участник повторяет один сквозной запуск. Для mid-review достаточно честного текущего статуса; модели реализуют студенты. FM — дополнительная задача после основного сравнения.

## Зафиксировать протокол оценки и подготовить mid-review

Цель: защитить проверяемую гипотезу и корректный эксперимент.

- [ ] Уточнить docs/research_plan.md вместе с командой.
- [ ] Реализовать общий расчёт logloss и ROC-AUC и проверить на небольшом примере.
- [ ] Согласовать одинаковые splits, правила early stopping и бюджет подбора.
- [ ] Завести Run ID и заполнять docs/experiment_log.md.
- [ ] Явно описать отличия от исходной статьи и ограничения.
- [ ] Перерисовать схему DCN самостоятельно.
- [ ] Собрать защиту по docs/midreview/README.md и провести две репетиции 6 октября.

Готово: каждый объясняет вопрос, baseline, метрики и ограничения. Нет выдуманных результатов; завершённый код к 7 октября не обязателен. До финала запланировать несколько seed.
