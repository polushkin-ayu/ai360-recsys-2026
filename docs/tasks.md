## [#1 — Подготовить небольшой срез MovieLens и общий split](https://github.com/polushkin-ayu/ai360-recsys-2026/issues/1)

- [ ] Источник/checksum, воспроизводимая выборка пользователей и seed; ориентир 10–20 тысяч оценок уточнить по пилоту.
- [ ] ID строк, размеры и распределение рейтингов; не выбирать срез по target.
- [ ] Общий train/validation/test, словари по train, отсутствие пересечений.
- [ ] Правило неизвестных ID и доля сохранённых строк основной метрики.
- [ ] Общие форматы входов/predict, RMSE на ручном примере и инструкция запуска.

Готово: коллега воспроизводит срез и split. Сырые данные не коммитим. DCN при сохранении использует те же данные.

## [#2 — Реализовать bias-модель и FM на MovieLens](https://github.com/polushkin-ayu/ai360-recsys-2026/issues/2)

- [ ] Bias и FM второго порядка по user/item, согласованный интерфейс.
- [ ] Равенство прямого/быстрого forward, проверка градиентов.
- [ ] Равенство FM и MF с bias при одинаковых параметрах.
- [ ] Обучение на маленьком представимом примере как техническая проверка.
- [ ] Конфигурации, seed, регуляризация, остановка по validation, команда пилота.
- [ ] Loss, validation RMSE, число параметров и время.

Готово: коллега повторяет пилот bias/FM. NumPy или PyTorch/autograd — выбор команды. Жанры после основного сравнения; высшие порядки вне обязательного объёма. Код пишут студенты, завершение к mid-review не обязательно.

## [#4 — Необязательный DCN на 1–2 человека](https://github.com/polushkin-ayu/ai360-recsys-2026/issues/4)

- [ ] На контрольных точках сегодня и во вторник решить, продолжать ли направление; при блокерах FM помочь основной команде.
- [ ] Если продолжаем, разобрать исходную DCN 2017, нарисовать схему и объяснить cross-слой.
- [ ] Если есть ресурс на код: общие срез/split, DNN → DCN с той же deep-веткой и embeddings, выход без sigmoid, MSE.
- [ ] Проверить формулу и градиенты; записать RMSE, параметры и время.

Можно ограничиться теорией или отказаться совсем. Это адаптация CTR-архитектуры к регрессии, не воспроизведение оригинального эксперимента. Не задерживаем защиту FM.
