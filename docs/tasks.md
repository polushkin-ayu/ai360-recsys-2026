# Задачи до mid-review

Исполнителей выбирает команда; существующие Issues #1–#3 обновляются под FM.

## [#1 — Подготовить синтетику и MovieLens 100K с воспроизводимым split](https://github.com/polushkin-ayu/ai360-recsys-2026/issues/1)

Цель: общие данные для проверки идеи факторизации и практического сравнения.

- [ ] Реализовать небольшой генератор категориальных признаков: факторизованные и независимые попарные коэффициенты; фиксировать seed и шум.
- [ ] Проверить наличие категорий в train и отдельно отметить невстречавшиеся попарные сочетания в оценке.
- [ ] Подготовить MovieLens 100K: источник, checksum, признаки и оценки.
- [ ] Зафиксировать train/validation/test; описать неизвестные ID и правила фильтрации.
- [ ] Учить словари и статистики только на train.
- [ ] Добавить проверенную инструкцию в data/README.md и согласовать формат с авторами моделей.

Готово: другой участник воспроизводит данные и split. Сырые данные не коммитятся. До mid-review достаточно маленького примера и протокола; полные эксперименты — после него.

## [#2 — Реализовать FM второго порядка и линейные baselines](https://github.com/polushkin-ayu/ai360-recsys-2026/issues/2)

Цель: сравнить независимые и факторизованные взаимодействия.

- [ ] Согласовать формат признаков и общий интерфейс predict/обучения.
- [ ] Для синтетики реализовать линейную модель, независимые попарные взаимодействия и FM второго порядка.
- [ ] Для MovieLens подготовить bias-модель и FM по user/item ID.
- [ ] Проверить равенство прямого и быстрого вычисления FM и корректность градиентов на маленьком примере.
- [ ] Проверить совпадение FM по двум ID с MF с bias при одинаковых параметрах.
- [ ] Добавить конфигурации, seed, регуляризацию и остановку по validation.
- [ ] Проверить обучение на маленьком заведомо представимом примере; считать параметры и время.

Готово: другой участник повторяет небольшой запуск. Модели пишут студенты. NumPy или PyTorch/autograd — выбор команды. Дополнительные признаки и высшие порядки — после обязательного объёма. Завершённый код к mid-review необязателен.

## [#3 — Зафиксировать протокол FM и подготовить mid-review](https://github.com/polushkin-ayu/ai360-recsys-2026/issues/3)

Цель: защитить проверяемую гипотезу об обобщении при разреженности.

- [ ] Согласовать docs/research_plan.md и общий расчёт RMSE; проверить метрику на маленьком примере.
- [ ] Зафиксировать одинаковые splits, регуляризацию/подбор по validation и сопоставимый бюджет моделей.
- [ ] Запланировать RMSE от объёма train и контрольный сценарий, неблагоприятный для малой размерности факторов.
- [ ] Вести docs/experiment_log.md: commit, конфигурация, данные, seeds, метрики, вывод.
- [ ] Описать ограничения генератора, обработку новых пар/ID и отличия от Netflix-экспериментов статьи.
- [ ] Самостоятельно нарисовать схему FM и собрать защиту по docs/midreview/README.md.
- [ ] Провести две репетиции 6 октября; до финала запланировать несколько seed.

Готово: каждый объясняет вопрос, формулу, baseline, RMSE и ограничения. Нет выдуманных результатов; готовая реализация к 7 октября не обязательна.
