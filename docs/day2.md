## Общая теория DL

Обе тройки изучают весь блок. Основной пример — рейтинг фильма, скалярный выход и MSE. Sigmoid и logloss разбираем кратко для понимания исходной CTR-постановки DCN. Цепочка: признаки → обучаемые векторы → преобразования → предсказание → loss → градиенты → обновление. Отличаем вычисление градиентов от шага оптимизатора.

## Раздельная работа

FM: формула второго порядка, независимые и факторизованные коэффициенты, прямое и быстрое вычисление, синтетический эксперимент и bias/FM на MovieLens.

DCN: исходный cross-слой, размерности, deep-ветка и объединение; небольшая DNN, затем cross-ветка. На MovieLens используем регрессионный выход без sigmoid, MSE для обучения и RMSE для оценки.

Ментор первые 25–30 минут раздельного теоретического блока помогает DCN; FM работает по подготовленным вопросам. Затем проверяет FM и обе схемы.

Данные и метрику готовят совместно по одному представителю от каждой тройки; остальные начинают модели. Исходные поля и информация одинаковы, представление для моделей может различаться. Каждый участник понимает весь свой метод; отдельной роли только для презентации нет.

## Результат дня и контрольная точка

У каждой тройки есть схема, гипотеза, статус кода и проверяемые задачи на понедельник. У всей команды единый протокол, доступ к MovieLens и проверенный способ запуска для обеих подкоманд. При задержках сокращаем реализацию, сохраняя заключительные 40 минут.

Тройка DCN объясняет embedding, MLP, loss, обучение, размерности cross-слоя и сравнение с DNN. Если этого пока нет, ментор обсуждает сокращение DCN до теоретического сравнения и объединение практических усилий вокруг FM. До mid-review поддерживаем два направления; после него уточняем роль DCN в постере. FM пока основная статья.
