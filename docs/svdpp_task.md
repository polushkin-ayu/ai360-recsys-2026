## 3. Точная формула SVD++

Используй:

```math
\widehat r_{ui} = \mu+b_u+b_i+ q_i^\top(p_u+h_u),
```

где

```math
h_u= \begin{cases} \displaystyle\frac{1}{\sqrt{|N_u|}}\sum_{j\in N_u}y_j, & |N_u|>0,\\[6pt] 0,& |N_u|=0. \end{cases}
```

Обозначения:

- `\mu` — среднее рейтингов только TRAIN, фиксированная константа;
- `b_u` и `b_i` — обучаемые смещения пользователя и фильма;
- `p_u\in\mathbb R^k` — явный фактор пользователя;
- `q_i\in\mathbb R^k` — фактор целевого фильма;
- `y_j\in\mathbb R^k` — отдельный фактор фильма для неявной истории;
- `N_u` — множество уникальных фильмов, оценённых пользователем `u` в TRAIN;
- `k` — размерность латентного пространства.

Таблицы независимы:

```text
P.shape = (n_users, k)
Q.shape = (n_items, k)
Y.shape = (n_items, k)

```

Не разделяй Q и Y одними параметрами. Значения рейтингов из истории не являются коэффициентами `y_j`: в `h_u` входит факт взаимодействия, а не величина оценки.

`\mu` вычисляется один раз по train и не обновляется оптимизатором. Сохраняй её как buffer либо явно замороженное значение. Смещения и все три факторные таблицы обучаются.

Реализуй непосредственно указанную выше формулу. Не добавляй дополнительные взаимодействия из формулы (19) статьи.

## 7. Loss и RMSE SVD++

Обучай по усреднённой MSE с явной L2-регуляризацией:

```math
L(B)= \frac{1}{|B|} \sum_{(u,i)\in B} (\widehat r_{ui}-r_{ui})^2 + \frac{\lambda_{\mathrm{bias}}}{n_{\mathrm{train}}} \left(\|b_U\|^2+\|b_I\|^2\right) + \frac{\lambda_{\mathrm{factors}}}{n_{\mathrm{train}}} \left(\|P\|_F^2+\|Q\|_F^2+\|Y\|_F^2\right).
```

`n_{\mathrm{train}}` — число всех train-наблюдений, не размер batch. `\mu` не обучается и не регуляризуется. Все нормы в этой конвенции берутся по полным таблицам параметров.

Не добавляй одновременно отдельную неучтённую `weight_decay`.

Эта конвенция и Adam не обязаны повторять SGD Surprise. В отчёте раздели совпадение формулы предсказания и различия обучения.

Обучай только новую `SVDPlusPlus`. Во всех её запусках `\mu` — фиксированное среднее train. Существующие реализации других участников не изменяй ради этого эксперимента.

Проверь, что `reset_parameters` не снимает заморозку и значение не меняется при `optimizer.step`.

Отдельно сохраняй:

```text
train_mse
train_loss_with_regularization
train_rmse
validation_rmse

```

Выполняется:

```text
train_rmse = sqrt(train_mse)

```

`sqrt(train_loss_with_regularization)` не является RMSE.

Итоговую оценку вычисляй существующими функциями:

```python
from src.metrics import require_same_row_ids, rmse_by_row_id

```

Проверяй `row_id` и порядок внутри каждого запуска и между запусками SVD++. Не допускай broadcasting, NaN/Inf и неявного clipping.

Зафиксируй `clipping=False` во всех запусках SVD++. Прогнозы вне [1, 5] допустимы.
