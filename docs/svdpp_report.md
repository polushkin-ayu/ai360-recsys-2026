# SVD++ на полном MovieLens 1M: батчи по оценкам

Обучены 13 значений k: 1,2,3,4,5,10,20,30,40,50,100,150,200, seed 11.
k=6,7,8,9,15 отложены по просьбе пользователя.

Батч содержит 1024 оценки, каждая эпоха покрывает все 700146 оценок train
и выполняет 684 отдельных обновления Adam. Максимум 25 эпох, patience=10,
проверка validation после каждой эпохи. Параметры фиксированы, как у FM:
lr=0.001, reg_bias=0.01, reg_factors=10, init_std=0.01.
Regularization делится на N train. Формула SVD++ использует независимые P,Q,Y,
фиксированное среднее train и только train-истории. Разреженная матрица
историй неизменна; H @ Y и градиенты пересчитываются на каждом обновлении.
Прогнозы не обрезаются. FM-код и обучение других моделей сохранены.

Подготовленные train/validation/test CSV побайтно совпадают с общим split.
После исключения cold items: train 700146, validation 150002, test 149990,
6040 пользователей и 3652 фильма.

## Сравнение и ограничения

В записанном эксперименте FM минимум среднего validation RMSE при k=100:
0.85017475, sample SD 0.00025886 по трём seeds. Здесь SVD++ имеет один seed,
поэтому его разброс неизвестен. Изменены одновременно число обновлений,
батчи, lr, инициализация и коэффициенты регуляризации; изменение кривой
нельзя приписать только одному из этих факторов. Прежний лучший k=6 сейчас
отложен. Найден минимум по активным 13 k, а не по исходным 18 значениям.

До лимита 25 эпох дошли k=1,2,3,4,5,10,20; сходимость не гарантируется.
Результаты прошлых опытов на этом test уже известны, поэтому это повторное
сравнение на существующем test, а не новый независимый holdout.
