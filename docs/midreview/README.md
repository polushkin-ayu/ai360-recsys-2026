# Mid-review 7 октября

Защищаем концепт исследования **FM второго порядка** по основной статье Factorized Polynomial Regression Models. Завершённый код не обязателен. DCN — возможное дополнение, а не обязательная часть защиты. Официальный регламент уточняем у организаторов; внутренняя репетиция — 7 минут выступления и 8 минут вопросов.

## История выступления

1. Почему независимые взаимодействия трудно оценивать при разреженности.
2. Как факторизация связывает параметры разных пар: собственная схема, формула и обучение FM.
3. Гипотеза: добавление взаимодействий улучшает RMSE относительно bias-модели; результат заранее неизвестен.
4. Небольшой срез MovieLens: как выбран, какой размер и какие ограничения репрезентативности.
5. MovieLens: bias/FM, RMSE, split и подбор по validation.
6. Что уже проверено, что ещё предстоит измерить; ограничения и план до 14 октября.

DCN включаем только если есть понятный вклад в рассказ и остаётся время. Для него отдельно объясняем адаптацию к рейтингу и сравнение DNN/DCN; отсутствие этого направления не является пробелом исследования FM.

## Самопроверка

- Каждый объясняет разницу выразительности, оптимизации и обобщения.
- Не обещаем выигрыш FM заранее; ограничения выбранного среза названы.
- Показываем долю оценки на известных ID и не заявляем результат на холодном старте.
- FM по user/item ID не выдаём за отдельный от MF с bias класс модели.
- Настройки выбираем по validation, не по test.
- Отличия от Netflix-экспериментов статьи названы.
- Схема нарисована командой, не скопирована скриншотом.
- Фактические результаты отделены от планируемых; пилот не доказывает устойчивость.
- 6 октября проводим две репетиции, вопросы адресуем разным участникам.

К финальному A0-постеру сохраняем реальные кривые loss и validation RMSE, таблицы, сравнение bias/FM и примеры предсказаний. Интерпретируем фактическую динамику, не требуем монотонного снижения validation RMSE. Срок отправки в печать уточнить отдельно. Не создаём фиктивных графиков.
