# Mid-review 7 октября

Защищаем концепт исследования. Код может быть не завершён. Официальный регламент выступления уточнить у организаторов; для внутренней репетиции можно использовать 7 минут выступления и 8 минут вопросов.

## Каркас выступления

1. Проблема: зачем нужны взаимодействия признаков.
2. FM как основа и идея DCN.
3. Собственная схема модели и ключевая формула.
4. Исследовательский вопрос и гипотеза.
5. Данные, baseline, метрики и протокол сравнения.
6. Текущий статус, ограничения и план до 14 октября.

## Самопроверка

- Любой участник объясняет основную идею и свою часть работы.
- Не путаем выразительность модели, обучение и обобщение.
- Не обещаем прирост заранее.
- Не подбираем параметры по test.
- Отличия от оригинального эксперимента названы явно.
- Схема перерисована командой, не скопирована скриншотом.
- Есть две репетиции с вопросами.

Для финального A0-постера заранее сохраняем графики обучения и качества, небольшую таблицу результатов и примеры предсказаний. Срок отправки в печать уточнить отдельно.
