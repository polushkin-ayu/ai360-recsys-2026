# Код

Студенты реализуют подготовку среза MovieLens, split, обработку ID, RMSE, bias-модель, FM второго порядка и цикл обучения. Авторы данных и моделей заранее согласуют интерфейсы.

Проверки: прямое/быстрое вычисление FM, градиенты, равенство MF с bias при одинаковых параметрах, маленький представимый пример. Искусственные примеры — только технические проверки.

Дополнительно: жанры. Необязательный DCN: DNN и исходная DCN 2017 на том же срезе, с выходом без sigmoid и MSE.
