# Код

Реализацию пишет команда: генератор синтетики, подготовка MovieLens, линейные baselines, FM второго порядка, обучение и общий расчёт RMSE. Согласуйте интерфейсы до параллельной работы. Поддержите явное и быстрое вычисление FM для проверки равенства. NumPy с явными градиентами или PyTorch с autograd — выбор команды.
