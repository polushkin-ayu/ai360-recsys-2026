# Код

Общее: подготовка MovieLens, split, обработка признаков и RMSE. Представители обеих троек согласуют интерфейсы и используют общий код.

FM: генератор синтетики, линейная модель, независимые взаимодействия, bias-модель и FM второго порядка; прямое/быстрое вычисление и проверка градиентов.

DCN: небольшая DNN и исходная DCN 2017, одинаковые deep-ветки и схема embeddings. На MovieLens — скалярный выход без sigmoid, MSE. Реализацию пишут студенты.
