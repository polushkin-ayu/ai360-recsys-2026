# Совместная работа

Одна небольшая задача — одна ветка и один pull request. Код моделей пишут студенты; ментор обсуждает постановку, проверяет интерфейсы и важные изменения.

## Первый вклад

Клонируйте репозиторий по URL с его страницы. В локальной копии:

```bash
git switch main
git pull --ff-only
git switch -c docs/my-first-change
# Внесите небольшую правку.
git add README.md
git commit -m "Clarify project description"
git push -u origin docs/my-first-change
```

Откройте pull request и попросите другого студента проверить изменение. Выбирайте уникальное имя ветки. Не используйте общие аккаунты.

## Перед объединением

- Объясните, какую задачу решает изменение.
- Приложите выполненную проверку или команду запуска и её результат.
- Другой студент читает изменение; важные методологические решения обсуждаются с ментором.
- Сохраняйте рабочую версию в main. Устраните конфликты до объединения.
- Один notebook одновременно редактирует одна пара. Общую логику переносите в src.
- Не добавляйте датасеты, веса, секреты и большие логи.

## Результаты

Перед измеряемым запуском сохраните код в commit. Запишите commit, конфигурацию, seed, описание выборки и split. Если запускали с незакоммиченными изменениями, зафиксируйте это; такой запуск нельзя считать полностью воспроизводимым по одному hash.

Подбирайте настройки по validation. Test используйте для финальной оценки выбранных моделей.
