# Опубликованная копия результатов

Здесь находятся метрики, графики, истории, протокол, снимок численных исходников
и проверка завершённой серии: 13 значений k, seed 11, до 25 эпох.
k=6,7,8,9,15 отложены. Полный отчёт: REPORT_RU.md.

Данные, model.pt и last.pt остаются локально и в Git не включаются.
verification.json описывает полный локальный каталог, поэтому его manifest
также содержит SHA256 отсутствующих здесь checkpoint. RMSE пересчитаны из
весов всех 13 моделей и совпали точно; фактические счётчики Adam проверены.
Этот каталог нельзя использовать для продолжения без локальных checkpoint.

Снимок source_snapshot.zip сохраняет байты семи численных исходников
и experiment_config.json; код запускался с локальными изменениями, что
записано в protocol.json. Одного старого commit hash для воспроизведения
недостаточно: используйте исходники из снимка вместе с текущим проектом,
указанными версиями библиотек и проверенными данными.

Время 98.64 минуты — сумма измеренных завершённых эпох, а не полное время
от первого запуска до публикации. Границы измерения указаны в REPORT_RU.md.
Сопоставление FM использует сохранённые результаты трёх seeds из общего
репозитория; новая серия SVD++ содержит один seed.
