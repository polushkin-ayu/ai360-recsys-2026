# Данные

Основные источники: небольшой контролируемый синтетический генератор и [MovieLens 100K](https://grouplens.org/datasets/movielens/100k/). Задача — регрессия; для MovieLens предсказываем оценку фильма.

Сырые и обработанные файлы исключены из Git. Добавьте проверенную команду получения/генерации, checksum и описание split. Генератор храните в src, его параметры в configs. Для синтетики проверяйте новые пары известных категорий; для MovieLens фиксируйте обработку неизвестных ID. Подробный протокол — docs/research_plan.md.

MovieLens — общий набор для FM и DCN. Обе тройки используют одинаковые строки, target, split и согласованные исходные поля; отдельные копии процедуры разбиения не создаём. Представители обеих подкоманд совместно поддерживают подготовку данных.
