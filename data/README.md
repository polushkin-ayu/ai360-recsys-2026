# Данные

Используем небольшой воспроизводимый срез [MovieLens 100K](https://grouplens.org/datasets/movielens/100k/). Target — численная оценка фильма. Отдельной синтетики нет.

Сырые и обработанные данные исключены из Git. Добавьте проверенную команду получения и подготовки, checksum, seed выборки и split, ID строк, фактические размеры и покрытие известных ID. Словари строятся только по train. Правила выборки и оценки — в [протоколе](../docs/research_plan.md).

Все модели используют один срез и split. При сохранении DCN она переиспользует подготовку данных FM.
