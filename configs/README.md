# Конфигурации

Фиксируем источник и checksum MovieLens, правило/seed среза, split ID и seed, признаки и обработку неизвестных ID. Для моделей: тип, k, регуляризация, оптимизатор, learning rate, batch size, эпохи, early stopping, seed инициализации. Настройки выбираем по validation. Начальные значения согласуем после пилота.

При сохранении DCN дополнительно записываем embeddings, deep-слои, число cross-слоёв и регрессионный выход. Все сравниваемые модели используют один split ID.
