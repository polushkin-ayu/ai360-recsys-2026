# Конфигурации

Фиксируйте датасет и split ID; для синтетики — сценарий, число полей/категорий, параметры истинной зависимости, масштаб шума и объём train. Для моделей — тип, k для FM, регуляризацию, оптимизатор, learning rate, batch size, эпохи и early stopping. Отдельно seed генерации/разбиения и seed обучения. Настройки выбираем по validation. Значения согласовать после пилота.

Для DCN фиксируем размеры embeddings, deep-слои, число cross-слоёв, активации и регрессионный выход. В сравнении DNN/DCN сохраняем deep-ветку и схему embeddings. Обе тройки ссылаются на один split ID.
